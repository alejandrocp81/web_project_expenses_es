# Proyecto web_project_expenses
Aplicación web interactiva que permite a los usuarios gestionar su presupuesto personal, registrar gastos y visualizar información básica sobre sus finanzas. La aplicación fue desarrollada como parte de mi formación en TripleTen, enfocándome en la implementación de lógica con JavaScript y manipulación del DOM.

## Tecnologías utilizadas:
HTML5 CSS3 JavaScript Manipulación del DOM Git
